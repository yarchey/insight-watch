# INSIGHT — тест Apple Watch

Это статическая демонстрация, не интеграция с конкретным приложением усложнений.

## Публикация без сервера
1. Создайте публичный репозиторий GitHub `insight-watch-demo`.
2. Загрузите `index.html` и `latest.json` в корень ветки `main`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Через несколько минут проверьте `https://USERNAME.github.io/insight-watch-demo/` и `https://USERNAME.github.io/insight-watch-demo/latest.json`.

Важно: это наш собственный формат JSON. Для конкретного приложения Apple Watch может потребоваться другой формат полей; не вставляйте URL в приложение до проверки его документации. В демо нет AI, автоматизации и Telegram.
